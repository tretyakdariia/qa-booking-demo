# QA Booking Demo

Тестовый QA-проект по ручному тестированию сервиса бронирования.

## О проекте

В рамках проекта я провела тестирование функциональности бронирования и REST API на основе предоставленных требований.

## Что было выполнено

- анализ требований;
- составление тест-кейсов;
- позитивное и негативное тестирование;
- проверка граничных значений;
- тестирование REST API;
- выполнение API-запросов в Postman;
- проверка кодов ответа и структуры данных;
- фиксация фактических результатов тестирования;
- анализ неоднозначностей и неполноты требований.

## Инструменты

- Postman
- REST API
- Google Sheets / Excel
- техники тест-дизайна

## Артефакты проекта

В репозитории находятся:

- тест-кейсы и результаты их выполнения;
- Postman Collection с API-запросами.

## Анализ требований

При выполнении задания были выявлены моменты, требующие уточнения:

1. Для поля «Имя гостя» указана минимальная длина, но не задана максимальная.
2. Указано, что в имени допустимы буквы, но не уточняется, разрешены ли кириллица и латиница.
3. В требованиях необходимо указывать фактический результат тест-кейса, однако в предоставленном шаблоне соответствующий столбец отсутствовал.
